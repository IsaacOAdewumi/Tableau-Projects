# Retail Sales and Profitability Dashboard in Tableau

**Author:** Isaac Olufemi Adewumi  
**Tools:** Tableau, spreadsheet or CSV data source  
**Project type:** Interactive visual analytics

## Project Overview

This project is designed to demonstrate how Tableau can turn structured retail or e-commerce data into an interactive dashboard for exploring sales and profitability. The report will focus on clear comparisons, useful filters, and a logical visual narrative.

The exact metrics, dimensions, and findings will be determined by the dataset used. No specific business outcomes are claimed until the workbook has been built and validated.

## Business Questions

- How do sales and profit vary across the available time periods?
- Which products or categories contribute most to sales and profit?
- Are there categories or segments with high sales but comparatively low profit?
- How do results differ across regions or customer segments, if those fields are available?
- Which patterns deserve further business investigation?

## Skills Demonstrated

- Connecting to and inspecting a data source
- Data preparation and field validation
- Calculated fields and KPI definitions where needed
- Interactive dashboards, filters, and tooltips
- Appropriate chart selection and visual hierarchy
- Dashboard testing and evidence-based interpretation

## Planned Dashboard Components

- KPI summary for the measures supported by the dataset
- Sales and profit trends over time
- Product or category comparisons
- Regional or segment analysis where applicable
- Filters for relevant dates, categories, and other available dimensions

## Planned Workflow

1. Identify and document the data source.
2. Check field types, missing values, and calculation requirements.
3. Create the required worksheets and calculated fields.
4. Assemble the dashboard and configure interactions.
5. Validate totals and comparisons against the underlying data.
6. Capture preview images and write a concise interpretation of the findings.
